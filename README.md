# ARCHA Mountain Project

Демо-сайт интернет-магазина одежды и снаряжения для гор и города (Бишкек).

Один файл `index.html` и папка `img/` с фотографиями. Сборка и сервер не нужны:
откройте `index.html` в браузере или включите GitHub Pages.

## Что работает

- каталог из 14 товаров с фильтрами и переключением цветов
- быстрый просмотр с выбором цвета, размера и количества
- корзина с бесплатной доставкой от 10 000 сом, избранное, поиск
- переключение цен сом / USD, мобильная версия

Оплата не подключена. Телефон и адрес магазина в тексте сайта — заглушки.

## Как опубликовать на GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
Через минуту сайт будет доступен по адресу `https://<имя-пользователя>.github.io/archa/`.
